# Legion Go 2 fixes

Community fixes for the Lenovo Legion Go 2. Each fix has its own folder with
step-by-step instructions, and none needs root access.

## Fixes

No fixes are published yet.

## Versions

Each fix is versioned on its own with git tags named `<fix>-v<version>`, such
as `brightness-slider-v1.0.0`. Instructions always name a tag, so a command
installs exactly the version you read. Tags are never moved or deleted; a
change gets a new tag.
